# [WORKING TITLE]

A short-session action RPG for phones, played in the browser. Every run is complete in itself, loot changes how you play, and the game never asks for your time when you're not playing.

> **Status:** early development. The specifications are being written; there is nothing playable yet. See [`docs/STATUS.md`](docs/STATUS.md) for the current state.

## What it is

- **Runs of 5–10 minutes** that you can pause and resume at any moment.
- **Loot that changes how skills behave**, not just bigger numbers, and a permanent codex so no legendary drop is ever wasted.
- **A challenge ladder** that tests your build and your skill, not the hours you've put in.
- **Fully playable offline.** It's a Progressive Web App: open it from a link and add it to your home screen. No app store, no account needed.

## What it will never have

No microtransactions, loot boxes, energy systems, timers, daily quests, login streaks, or time-limited content. The full list and the reasoning are in the [Vision](docs/vision.md).

## How this project is built

This is a solo evening hobby project, developed largely by AI coding agents working autonomously, with the owner reviewing and deciding in the evenings.

It follows **spec-driven development** with the [AI Unified Process](https://unifiedprocess.ai) (AIUP), spec-anchored: the specifications are the source of truth, they live in this repo next to the code, and code is derived from use cases. Nothing gets built without a use case.

The project also has a hard rule of **zero cost**: free tools and non-expiring free tiers only.
